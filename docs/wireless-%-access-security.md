# WIRELESS AND ACCESS SECURITY

### Introduction

Wireless network security involves protecting wireless networks and connected devices from unauthorized access and other security threats. Network access security focuses on ensuring that only authorized users and devices can access network resources.

NIST recommends securing wireless network components throughout their design, installation, maintenance and monitoring stages (Souppaya and Scarfone, 2012).

### Wireless Network Security

Wireless networks use radio communication to connect devices without physical cables.

Although convenient, wireless networks may be exposed to unauthorised access if they are poorly configured.

### Wireless Network Security Practices

Use Strong Wi-Fi Passwords

A strong and unique Wi-Fi password helps prevent unauthorised individuals from connecting to the network.

Use Modern Encryption

Wireless networks should use supported, secure encryption configurations.

WPA2 or WPA3 should be preferred where supported by the equipment.

Change Default Router Credentials

Default administrator usernames and passwords should be changed to prevent unauthorised management access.

Update Router Firmware

Router firmware should be updated to address security weaknesses and improve protection.

Disable Unnecessary Remote Management

Remote administration should be disabled when it is not required or should be restricted to authorized administrators.

These practices are consistent with security recommendations for wireless networks and network equipment (CISA, 2024; Souppaya and Scarfone, 2012).

### Network Access Control

Network access control ensures that users and devices are only allowed to access resources they are authorized to use.

It helps protect confidential information and reduces the possibility of unauthorised network activity.

### Access Control Practices

Organizations should:

✓ Create separate accounts for different users. ✓ Use strong authentication methods. ✓ Grant users only the permissions they need. ✓ Remove access when employees leave. ✓ Monitor access to important network resources. ✓ Protect administrator accounts.

The principle of granting only necessary permissions helps reduce unnecessary access to network resources (Chandramouli, 2022).

### Network Maintenance

Network administrators should regularly:

1. Check connected devices.

2. Review network security settings.

3. Install available security updates.

4. Monitor unusual network activity.

5. Review user access permissions.

6. Maintain backups of important configurations.

### Conclusion

Wireless and access security are important parts of network protection.

Using strong authentication, secure wireless configurations and appropriate access restrictions helps protect networks against unauthorized access.
