# FIREWALL SECURITY

## 2.1 Introduction

A firewall is a security device or software
that monitors and controls network traffic
according to predefined security rules.

It helps control communication between networks
or devices with different security requirements
(Scarfone and Hoffman, 2009).

## 2.2 Functions of a Firewall

A firewall performs several important functions:

### 1. Traffic Filtering

It examines network traffic and allows or blocks
connections based on configured rules.

### 2. Preventing Unauthorised Access

It helps restrict unwanted network connections
from reaching protected systems.

### 3. Network Monitoring

Some firewall solutions provide logs that
help administrators review network activity.

### 4. Controlling Network Communication

Firewalls can control which services and
connections are permitted between networks.

## 2.3 Types of Firewalls

### Packet-Filtering Firewall

Examines network packets and makes decisions
based on information such as IP addresses,
ports and protocols.

### Stateful Inspection Firewall

Tracks the state of network connections and
uses connection information when deciding
whether traffic should be permitted.

### Proxy Firewall

Acts as an intermediary between users and
external services.

### Host-Based Firewall

Runs on an individual computer or device
to control its incoming and outgoing traffic.

## 2.4 Firewall Security Practices

Organisations should:

- Configure firewall rules appropriately.
- Block unnecessary network connections.
- Review firewall logs regularly.
- Update firewall software and devices.
- Remove outdated or unnecessary rules.
- Restrict access to firewall administration.

NIST recommends that firewall policies should
be properly established, configured, tested
and maintained (Scarfone and Hoffman, 2009).

## 2.5 Importance of Firewalls

Firewalls provide an important layer of
network protection.

However, they should not be treated as the
only security measure. Other controls such
as authentication, updates and monitoring
are also necessary.

## 2.6 Conclusion

Firewalls help protect networks by controlling
network traffic and restricting unwanted
connections.

Proper configuration and maintenance are
important for effective firewall security.
